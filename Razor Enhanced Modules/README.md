# Frogmancers Razor Enhanced Module Expansion Library

If you're unable to launch any of my scripts do to the "no module found" message then you're missing one of these.

These can be found on older Razor Enhanced installations. 
* -Official Razor Enhanced Website: https://ultimatools.github.io/razorenhanced.github.io/index.htm
* -Official Github: https://github.com/UltimaTools/RazorEnhanced/releases


Simply clone or download/extract this portion of the repo into your Razor Enhanced folder. It the entire LIB folder should go right in //razorenhanced/
Happy scripting
